# Cybersecurity Internship – Week 2

## Footprinting, Reconnaissance & Network Scanning

This repository documents the practical tasks completed during Week 2 of my Cybersecurity & Ethical Hacking Internship at Networkwalks.

## Objectives

- Understand footprinting and reconnaissance techniques.
- Explore publicly available domain information.
- Identify website technologies and DNS records.
- Perform network discovery using Zenmap.
- Identify live hosts and understand network topology.

## Tools Used

| Tool | Purpose |
|---|---|
| Kali Linux | Reconnaissance environment |
| WHOIS | Domain registration lookup |
| WhatWeb | Website technology fingerprinting |
| Nslookup | DNS resolution |
| Curl | HTTP header inspection |
| Wafw00f | WAF detection |
| DNSRecon | DNS enumeration |
| Zenmap | Network scanning |
| Windows CMD | Local network identification |

## Activities Performed

### 1. Footprinting & Reconnaissance
Performed domain reconnaissance using:
- WHOIS
- WhatWeb
- Nslookup
- Curl
- Wafw00f
- DNSRecon

### 2. Network Scanning
Used Zenmap to:
- Discover live hosts on the local network.
- Identify IP and MAC addresses.
- Perform Ping Scans.
- Generate a network topology.

- `Report/` – Detailed practical report.

## Key Learnings

- Understanding the importance of reconnaissance in cybersecurity.
- Learning how to identify publicly exposed domain information.
- Understanding DNS enumeration and website fingerprinting.
- Gaining practical experience with network scanning.
- Learning to document security observations and potential risks.

## Disclaimer

All activities were performed for educational purposes on systems and networks where appropriate authorization was available. No exploitation or vulnerability validation was performed.

Unauthorized scanning or access to systems is not permitted.
